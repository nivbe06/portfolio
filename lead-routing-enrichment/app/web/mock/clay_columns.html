What this layout argues that the row layout cannot. Provider spend is a column total, so the cost lever sits in the header where the decision is made. Two greyed column groups say “we did not fire everything” more convincingly than any copy. Apollo appears only where the waterfall actually fell through to it, marked fallback, which makes the Gate B retry legible. And provenance is per cell, so “show the receipt” costs no extra screen.
