# Product

## Register

product

## Users

Two real audiences at once: (1) in-product — a RevOps/GTM operator bringing in a
partial lead list, choosing what to enrich, reviewing AI+deterministic
reconciliation, writing clean records to CRM; (2) the actual audience — Talon.One's
interview panel evaluating this as a take-home for the GTM AI Engineer role,
judging engineering, product, and design judgment together.

## Product Purpose

Deterministic-first, AI-last lead enrichment. Bring partial account/contact
records, enrich via specialised providers (Clearbit, ZoomInfo, Apollo,
Crunchbase) with anti-fire-all provider selection, reconcile to a canonical
vocabulary (deterministic DB first, LLM only when nothing matches), surface AI
mapping confidence separately from provider match confidence, give every
low-confidence flag a real resolution path, then write to CRM. Success =
demonstrably governed and cost-disciplined AI, not a black box.

## Brand Personality

Precise. Honest. Restrained. Talon.One's own brand system (indigo/lime/teal,
Syne + Outfit) — never a generic AI-tool palette.

## Anti-references

Generic SaaS-AI dashboard slop: gradient hero cards, badge/pill sprawl with no
explanation, silent black-box reconciliation, fake urgency, hidden costs, dark
patterns of any kind (explicitly audited clean this session).

## Design Principles

1. Deterministic-first, AI-last - never spend a provider call on data already trusted.
2. Show the receipt - every reconciled value carries visible provenance.
3. Every review flag ships with a real resolution path, not just a warning.
4. Cost is shown as effort/scope in the flow; currency only in the admin dashboard.
5. Craft is table stakes - real tokens, real interaction states, no eyeballed one-offs.

## Accessibility & Inclusion

WCAG 2.1 AA (contrast, focus-visible, aria-expanded, reduced-motion all audited
this session). No additional stated accommodation needs.
